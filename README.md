# 时间账本

记录「时间花在哪」的小应用。电脑和手机用同一套页面，数据存在各自本机，靠**导出 / 导入 JSON** 完成多端同步。

一级分类用来出图表（工作 / 学习 / 生活 / 运动 / 休息），二级标签记录具体做了什么（写代码 / 开会 / 阅读……）。

## 打开方式

### 电脑（推荐）

双击 **`启动.cmd`**。会起一个本地服务并自动打开浏览器。

> 也可以直接双击 `index.html`，但本地文件模式（`file://`）下浏览器对 localStorage 的持久化不如 http 可靠，所以推荐用上面这种方式。

### 手机

1. 电脑上双击 `启动.cmd`，窗口里会打印一行 `手机：http://192.168.x.x:5180`
2. 手机连**同一个 WiFi**，浏览器打开这个地址
3. 在浏览器菜单里选「添加到主屏幕」，之后像 App 一样从桌面打开

> 如果手机打不开：多半是 Windows 防火墙拦了这个端口，放行 Node.js 即可；或者电脑和手机不在同一个网段。
>
> 局域网是 http，Service Worker 不会注册，所以没有离线缓存，但功能完全正常。部署到 https 后就能完整安装成 PWA。

## 多端同步

数据不会自动上传，全靠一个 JSON 文件在设备间搬运：

```
电脑：导出 time-tally-20260510-2130.json  ──►  发到手机（微信 / QQ / 网盘 / 隔空投送）
手机：导入这个文件                          ──►  合并
手机：再导出                                ──►  发回电脑
电脑：导入                                  ──►  两端一致
```

合并规则：

- 同一条记录（相同 id）以**修改时间较新的**为准，不会重复计数
- 分类按**名字**对齐——两端都叫「工作」的分类不会变成两个
- 删除是软删除，会跟着导入导出一起走，不会「删了又复活」
- 导出那一刻如果还在计时，这条会按当时时刻封口再导出；导入端的同名运行中记录不会被覆盖
- 导入报告会告诉你新增了几条、更新了几条

## 主界面

| 位置 | 功能 |
|---|---|
| 正中大圆按钮 | **开始** → 选一个二级标签立刻计时；计时中变红，点一下**停止** |
| 大按钮下方三个入口 | **补记** / **导出** / **导入** |
| 常用标签 | 最近用过的 5 个二级标签，点一下直接开始；计时中点另一个就是**切段** |
| 今日记录 | 点任意一条可以改时间、改标签、加备注或删除；左右箭头可翻看前几天 |
| 底部 记录 / 统计 / 设置 | 主界面、图表、分类管理 |

切段的意思是：正在记「开会」时点「写代码」，会以同一秒结束上一段并开始下一段，不留缝隙也不重叠。

补记里给了 15 / 30 / 45 / 60 / 90 分钟的快捷按钮，跨零点会自动按跨天处理。

## 统计

今天 / 本周 / 本月 / 全部四个区间，给出总时长、一级分类占比环形图、分类明细、二级标签排行、近 7 天柱状图。

跨天的记录按当天实际覆盖的时段切分统计，不会把一整晚都算到某一天。

## 预览模式

没录过数据也想先看效果，可以在地址后面加 `?demo=1`：

- `index.html?demo=1` —— 带一批示例数据（只读，不会写进本地存储）
- `index.html?demo=1&view=stats` —— 直接看统计页

## 数据安全

- 数据只存在这台设备的浏览器里，**不上传任何服务器**
- 清理浏览器数据 / 换设备 / 隐私模式会丢数据，请定期「导出」备份
- 超过 7 天没导出，设置页会提醒
- iOS 对长期不打开的网页应用可能清理存储，装到主屏幕并定期打开、导出更稳妥

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 应用本体，单文件，无外部依赖，可离线 |
| `启动.cmd` | Windows 下双击起本地服务并打开浏览器 |
| `serve.mjs` | 局域网静态服务（给手机访问用） |
| `manifest.webmanifest` | 让浏览器把它当作可安装应用 |
| `sw.js` | 离线缓存，仅在 http/https 下生效 |
| `test-logic.cjs` | 逻辑自测 |
| `icons/` | 应用图标 |
| `screenshots/` | 界面截图 |

## 开发

无构建步骤，改完 `index.html` 刷新即可。

```bash
node test-logic.cjs
```

自测覆盖：区间裁剪、跨天切分、运行中条目按当前时刻计算、分组聚合与排序、导入合并（新增 / 修改时间优先 / 分类按名归并 / 未结束条目收缩 / 保护本地运行中的计时）。
